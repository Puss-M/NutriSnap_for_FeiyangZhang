# 🍎 NutriSnap AI

基于多模态 AI 的智能饮食分析系统 - 个性化营养管理助手

## ✨ 核心功能

### 👤 智能个人档案

- **个性化设置**：体重、身高、性别、年龄、活动水平
- **实时 BMI 计算**：自动计算并分类（偏瘦/正常/偏重/肥胖）
- **科学代谢计算**：基于 Mifflin-St Jeor 公式计算 BMR 和 TDEE

### 🎯 目标导向营养方案

- **增肌模式 💪**：高蛋白高碳水（2.2g 蛋白/kg + 卡路里盈余）
- **减脂模式 🔥**：高蛋白低碳水（2.4g 蛋白/kg + 卡路里赤字）
- **维持模式 ⚖️**：均衡营养（1.8g 蛋白/kg + 维持卡路里）

### 📊 营养追踪系统

- 📸 **智能食物识别**：上传图片自动识别食物
- 🎚️ **重量调整**：滑动条精确调整份量
- 📈 **实时进度**：可视化进度条显示今日摄入
- ✅ **一键记录**：快速添加到每日摄入

### 🤖 AI 营养助手

- 💬 **智能对话**：基于当前营养缺口提供建议
- 📍 **位置感知**：结合地理位置推荐附近购买建议
- 🎯 **个性化推荐**：根据目标和缺口智能推荐食物
- ⚡ **快捷提问**：一键发送常见营养问题

## 本地运行

如果您想在本地运行此应用：

1. 克隆仓库：

   ```bash
   git clone https://github.com/your-username/nutrisnap-ai.git
   cd nutrisnap-ai
   ```

2. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

3. 运行应用：

   ```bash
   streamlit run app.py
   ```

4. 在浏览器中访问 `http://localhost:8501`

## 📱 使用流程

### 第一步：设置个人档案

1. 打开应用，进入 **👤 个人资料** 标签页
2. 输入您的体重、身高、年龄、性别
3. 选择活动水平（久坐到运动员）
4. 选择健身目标（增肌/减脂/维持）
5. 查看自动计算的 BMI 和营养目标
6. 点击"保存个人资料"

### 第二步：追踪每日营养

1. 进入 **📊 营养追踪** 标签页
2. 查看基于您目标的每日宏量需求
3. 上传食物照片进行 AI 识别
4. 调整重量滑块以精确份量
5. 点击"添加到今日摄入"
6. 实时查看进度条更新

### 第三步：获取 AI 建议

1. 进入 **🤖 AI 助手** 标签页
2. 查看当前营养缺口
3. 输入问题，例如："我在红旗，今天差 150g 蛋白质，你建议我要买点什么吃？"
4. 获取个性化、位置感知的食物推荐
5. 使用快捷按钮快速提问常见问题
